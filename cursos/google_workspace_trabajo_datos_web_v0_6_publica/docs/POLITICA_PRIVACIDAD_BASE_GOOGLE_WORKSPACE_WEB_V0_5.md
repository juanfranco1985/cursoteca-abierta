# Política de privacidad base

Este curso no requiere crear cuenta, iniciar sesión ni enviar datos a un servidor propio.

El progreso y los historiales educativos se guardan localmente en el navegador mediante `localStorage`.

No se deben ingresar datos personales reales, contraseñas, correos privados, enlaces sensibles ni información confidencial en los ejercicios.

Si el usuario borra los datos del navegador, puede perder el progreso local.
