# ESTADO ACTUAL — Google Workspace para Trabajo y Datos Web v0.4

## Resumen

La versión v0.4 profundiza el curso con una capa de trabajo colaborativo. El objetivo es enseñar cómo compartir archivos, revisar permisos y sostener una rutina semanal con Google Drive, Gmail, Calendar, Sheets y Forms.

## Agregado principal

- Simulador de permisos de Drive.
- Casos de colaboración.
- Rutina semanal de organización.
- Checklist imprimible de permisos y archivos compartidos.
- Historial local no sensible de prácticas.
- Mejoras de acceso desde Home.
