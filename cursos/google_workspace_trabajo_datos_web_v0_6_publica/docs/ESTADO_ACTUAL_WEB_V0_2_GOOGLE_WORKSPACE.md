# Estado actual — Google Workspace para Trabajo y Datos Web v0.2

## Resumen

La versión v0.2 incorpora el núcleo diferencial del curso: un Laboratorio de Google Sheets para practicar con datos ficticios.

## Agregado principal

- Nueva ruta `#/sheets-lab`.
- Nueva ruta `#/sheets-dataset/{datasetId}`.
- Nueva ruta `#/sheets-exercise/{exerciseId}`.
- Nueva ruta `#/sheets-report`.
- Nuevo archivo `src/data/sheets_lab.json`.

## Contenido del laboratorio

- 3 datasets de ejemplo:
  - ventas simples de un local;
  - gastos de un equipo de trabajo;
  - respuestas de formulario de consultas.
- 5 fórmulas básicas:
  - SUMA;
  - PROMEDIO;
  - CONTAR.SI;
  - FILTRO;
  - SI.
- 4 ejercicios guiados.
- Mini reporte exportable como `.txt`.
- Historial local no sensible.

## Estado funcional

La versión se considera funcional como v0.2 de desarrollo. El próximo paso recomendado es una v0.3 con laboratorio Forms + Sheets o automatización conceptual de flujo de trabajo.
