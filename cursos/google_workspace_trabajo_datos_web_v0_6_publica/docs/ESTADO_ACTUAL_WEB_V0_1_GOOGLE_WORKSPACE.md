# Estado actual — Google Workspace para Trabajo y Datos Web v0.1

Primera versión del curso. Incluye estructura completa del curso, checklists, casos guiados, progreso local, manifest web, service worker y documentación base.

## Módulos
1. Google Drive y organización de archivos.
2. Google Docs para documentos de trabajo.
3. Google Sheets para planillas y datos.
4. Google Forms para recolectar información.
5. Gmail y Calendar para organización.
6. Presentaciones, colaboración y permisos.
