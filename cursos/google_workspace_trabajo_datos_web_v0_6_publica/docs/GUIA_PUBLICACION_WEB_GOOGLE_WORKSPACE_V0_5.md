# Guía de publicación web — Google Workspace para Trabajo y Datos v0.5

## Opciones recomendadas

- GitHub Pages.
- Netlify.
- Vercel.
- Carpeta dentro del portal de familia de cursos.

## Pasos

1. Probar localmente con Live Server.
2. Revisar consola del navegador.
3. Verificar carga de JSON.
4. Probar navegación completa.
5. Probar Service Worker en entorno servido por HTTP/HTTPS.
6. Capturar pantallas principales.
7. Subir carpeta del curso al hosting elegido.
8. Verificar rutas relativas.

## Nota

Si se integra al portal, actualizar `data/courses.json` del portal con la ruta final del curso.
