## Resumen

El curso enseña SQL introductorio aplicado a análisis de datos con módulos, lecciones, quizzes, checklists, casos guiados y un laboratorio SQL simulado.

## Funciones principales

- Curso de 6 módulos y 36 lecciones.
- 30 preguntas de quiz.
- Laboratorio SQL simulado.
- Tablas de ejemplo.
- Ejercicios guiados.
- Práctica libre con plantillas.
- Desafíos por dificultad.
- Ayudas contextuales para SELECT, WHERE, GROUP BY, JOIN y fechas.
- Comparador educativo de consulta escrita contra consulta sugerida.
- Reporte exportable como TXT.
- Progreso local y constancia interna.
