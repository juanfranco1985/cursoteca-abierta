# Política de privacidad base — SQL Práctico Web v0.5

El curso funciona localmente en el navegador.

## Datos

- No requiere login.
- No solicita datos personales.
- No usa backend.
- No envía información a servidores propios.
- No incluye analíticas ni publicidad.
- Guarda progreso local mediante `localStorage`.

## Recomendación

Usar solo datos ficticios, de ejemplo o anonimizados en prácticas y reportes. No ingresar nombres reales de clientes, correos, contraseñas, documentos, claves ni información sensible.
