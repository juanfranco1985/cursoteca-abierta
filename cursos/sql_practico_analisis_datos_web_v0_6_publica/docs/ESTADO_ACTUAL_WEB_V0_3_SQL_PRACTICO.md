# Estado actual — SQL Práctico para Análisis de Datos Web v0.3

La versión v0.3 profundiza el laboratorio SQL de v0.2 y agrega funciones de práctica más cercanas a un curso interactivo.

## Incorporado

- Práctica libre SQL con plantillas.
- Mini evaluador educativo de consultas.
- Desafíos por dificultad.
- Nuevos ejercicios de JOIN, fechas y calidad de datos.
- Reporte de avance SQL exportable como TXT.
- Historial local no sensible para prácticas libres y desafíos.
- Actualización de manifest, Service Worker y validador.

## Estado

Candidato de trabajo v0.3. Próxima evolución sugerida: v0.4 con mejoras visuales, guía didáctica del laboratorio, comparación entre consulta escrita y respuesta sugerida, mejor experiencia móvil y preparación hacia publicación.
