# Aviso legal y alcance educativo — SQL Práctico v0.5

Este curso tiene fines educativos e introductorios.

No reemplaza:

- documentación oficial de motores SQL;
- capacitación profesional especializada;
- revisión técnica de bases de datos productivas;
- asesoramiento de arquitectura, seguridad o gobierno de datos.

Las consultas, tablas y casos incluidos son simulados. Para bases reales se debe trabajar con datos autorizados, anonimizados cuando corresponda, y respetando políticas internas de privacidad, seguridad y gobierno de datos.
