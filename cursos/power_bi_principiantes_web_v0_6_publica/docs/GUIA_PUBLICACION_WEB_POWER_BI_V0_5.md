# GUÍA DE PUBLICACIÓN WEB — POWER BI PARA PRINCIPIANTES v0.5

## Objetivo

Publicar el curso como sitio web estático.

## Requisitos

- Mantener la estructura de carpetas.
- Publicar desde la raíz donde está `index.html`.
- No eliminar `src/data/`, `icons/`, `manifest.webmanifest` ni `service-worker.js`.

## Prueba local

1. Abrir la carpeta en VS Code.
2. Usar Live Server.
3. Revisar navegación principal.
4. Probar laboratorio, constructor de KPIs y storytelling.
5. Probar exportación `.txt`.
6. Revisar consola del navegador.

## Plataformas sugeridas

- GitHub Pages.
- Netlify.
- Vercel.
- Servidor web estático.

## Antes de publicar

- Revisar README.
- Revisar aviso legal.
- Revisar política de privacidad.
- Generar capturas.
- Probar en celular.
- Probar en escritorio.
- Probar recarga con Service Worker.
