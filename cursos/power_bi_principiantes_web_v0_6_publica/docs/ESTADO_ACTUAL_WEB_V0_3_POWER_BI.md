# Estado actual — Power BI para Principiantes Web v0.3

## Objetivo de la versión

Agregar un constructor educativo de KPIs y visualizaciones para que el usuario practique cómo diseñar un dashboard antes de construirlo en Power BI.

## Funciones agregadas

- Ruta `#/kpi-builder`.
- Ruta `#/dashboard-design-report`.
- Archivo `src/data/dashboard_builder.json`.
- Preguntas de negocio prediseñadas.
- KPIs sugeridos por pregunta.
- Visualizaciones recomendadas.
- Tarjetas simuladas de dashboard.
- Reporte de diseño exportable como `.txt`.
- Historial local no sensible de diseños.

## Estado

Candidato educativo v0.3 validado para continuar hacia v0.4.
