# AVISO LEGAL Y ALCANCE EDUCATIVO — POWER BI PARA PRINCIPIANTES

Este curso tiene finalidad educativa e introductoria.

No reemplaza:

- capacitación oficial de Microsoft;
- documentación técnica actualizada;
- políticas internas de datos;
- auditorías profesionales;
- revisión de dashboards reales;
- asesoramiento empresarial;
- certificaciones oficiales.

Los ejemplos son ficticios o simplificados. Las recomendaciones de visualización y storytelling son orientativas.

El usuario no debe cargar datos reales, sensibles, privados, confidenciales o empresariales en las herramientas de práctica.
