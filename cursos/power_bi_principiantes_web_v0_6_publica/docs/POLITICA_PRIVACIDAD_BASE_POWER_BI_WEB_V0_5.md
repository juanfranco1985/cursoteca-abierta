# POLÍTICA DE PRIVACIDAD BASE — POWER BI PARA PRINCIPIANTES WEB

## Datos personales

El curso no solicita nombre, correo, teléfono, usuario ni contraseña.

## Almacenamiento local

El progreso y algunas prácticas pueden guardarse en el navegador mediante `localStorage`.

## Datos sensibles

No se deben ingresar datos personales, financieros, empresariales reales, bases de clientes, ventas reales ni información confidencial.

## Internet

El curso está diseñado como sitio estático. No requiere login ni backend propio.

## Analíticas y publicidad

Esta versión no incluye analíticas, publicidad ni rastreo de terceros.
