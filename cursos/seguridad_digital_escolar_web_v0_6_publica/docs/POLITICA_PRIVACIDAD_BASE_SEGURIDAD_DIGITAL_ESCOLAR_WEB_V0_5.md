# Política de privacidad base — Seguridad Digital Escolar Web

## Datos personales

La versión base no utiliza login, backend, analíticas, publicidad ni tracking.

## Almacenamiento local

El curso puede guardar progreso, prácticas, resultados educativos y configuraciones en el navegador mediante `localStorage`.

La información queda en el dispositivo del usuario y puede borrarse desde la pantalla de progreso o limpiando los datos del navegador.

## Recomendación importante

No ingresar datos personales reales, nombres de menores, contraseñas, códigos, teléfonos, direcciones, capturas sensibles ni información íntima dentro de campos libres o reportes.

## Publicación futura

Si en el futuro se agrega backend, login, analíticas, formularios reales o integración externa, esta política debe revisarse y actualizarse antes de publicar.
