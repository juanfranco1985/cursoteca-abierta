# ESTADO ACTUAL — Seguridad Digital Escolar Web v0.1

## Resumen

Se creó el clon **Seguridad Digital Escolar Web v0.1** a partir de la familia de cursos web clonables.

## Contenido generado

- 6 módulos escolares.
- 36 lecciones estructuradas para lectura web.
- 30 preguntas de quiz.
- 6 checklists preventivos.
- 8 casos guiados para situaciones digitales escolares.

## Ejes pedagógicos

1. Identidad digital y huella online.
2. Contraseñas, privacidad y cuentas.
3. Redes sociales, reputación y exposición.
4. Grooming, acoso y pedidos peligrosos.
5. Juegos, skins, sorteos y cuentas robadas.
6. Cómo pedir ayuda y conservar evidencia.
