# Estado actual — Seguridad Digital Escolar Web v0.5

## Estado

Versión candidata de publicación web.

## Base técnica

- HTML, CSS y JavaScript.
- Datos locales en JSON.
- Progreso local con `localStorage`.
- Manifest web.
- Service Worker básico.
- Sin backend, sin login, sin analíticas y sin publicidad.

## Contenido funcional

- 6 módulos.
- 36 lecciones.
- 30 preguntas de quiz.
- 6 checklists.
- 8 casos escolares guiados.
- 5 mensajes copiables de pedido de ayuda.
- 8 ítems de conservación de evidencia.
- 6 escenarios escolares simulados.
- 3 guías para familias.
- 3 guías para docentes/preceptores.

## Funciones especiales

- Modo pedir ayuda.
- Checklist de evidencia.
- Señales de riesgo.
- Ruta para casos graves.
- Simulador de situaciones escolares.
- Reporte exportable de práctica.
- Guías de acompañamiento para familias/docentes.
- Protocolo educativo para casos graves.
- Reporte imprimible para conversar con adulto o escuela.

## Cierre v0.5

La versión agrega documentación pública, guías de publicación, guía de capturas, aviso legal, privacidad y checklist de publicación.

## Próximo paso opcional

Una v0.6 final pública podría limpiar documentación heredada, incorporar capturas reales, preparar demo online y reducir el paquete a una distribución más liviana.
