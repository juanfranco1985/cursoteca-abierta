# ESTADO ACTUAL — Seguridad Digital Escolar Web v0.4

## Estado

Versión orientada a acompañamiento escolar, familia y docentes.

## Base previa

Parte de Seguridad Digital Escolar Web v0.3, que ya incluía curso completo, modo pedir ayuda, evidencia y simulador escolar.

## Nuevas funciones

- Guías para familias.
- Guías para docentes y preceptores.
- Protocolo educativo para casos graves.
- Reporte imprimible para conversación con adulto o escuela.
- Nuevas rutas: `#/family-teacher-guides`, `#/guide-detail/{guideId}`, `#/school-protocol`, `#/adult-school-report`.
- Nuevo archivo `src/data/school_guidance.json`.
- Mejoras móviles y de impresión.

## Nota responsable

El curso es educativo y preventivo. No reemplaza acompañamiento familiar, intervención escolar, asesoramiento profesional, soporte de plataformas ni actuación de autoridades cuando corresponda.
