# Política de privacidad base

Esta versión no requiere cuenta de usuario, no tiene backend propio, no incluye analíticas y no envía datos del curso a servidores externos.

El progreso y preferencias se guardan en el navegador mediante `localStorage`. El usuario puede borrar esos datos desde las opciones del navegador o desde las herramientas internas del curso cuando estén disponibles.

Advertencia: si el usuario copia prompts y los pega en servicios externos de IA, esos servicios pueden tener sus propias políticas de privacidad. No se deben compartir datos sensibles ni información confidencial.
