# Estado público — Primeros Auxilios Digitales Web v0.6

## Estado

Versión pública liviana lista para prueba controlada en navegador.

## Objetivo de la v0.6

Convertir la v0.5 candidata a publicación en un paquete más presentable para usuario final, quitando documentación interna de clonación y dejando solo archivos útiles para uso, prueba y publicación.

## Incluye

- Curso completo con módulos, lecciones, quizzes, checklists y emergencias guiadas.
- Diagnóstico rápido digital.
- Mapa visual de rutas de emergencia.
- Checklist imprimible.
- Plan de acción copiable.
- Manifest web.
- Service Worker básico.
- Íconos.
- README público.
- Documentos de privacidad, alcance y publicación.

## Archivos principales

```text
index.html
styles.css
src/app.js
src/data/course_manifest.json
src/data/course_content.json
src/data/checklists.json
src/data/incidents.json
manifest.webmanifest
service-worker.js
icons/
docs/
store/screenshots/
```

## Diferencia contra v0.5

- Se retiraron documentos internos de clonación, prompts y auditorías acumuladas.
- Se actualizó la versión pública a v0.6.
- Se ajustó el README para usuario final.
- Se actualizó el cache del Service Worker.
- Se retiraron enlaces visibles a guía de clonación/publicación interna.
