# Política de privacidad base

Esta versión funciona como sitio estático.

## Datos

- No solicita registro.
- No pide nombre, correo, teléfono ni documento.
- No usa backend propio.
- No usa analíticas externas.
- No incluye publicidad.
- No vende datos.

## Progreso local

El progreso se guarda en `localStorage` del navegador. Si el usuario borra datos del navegador, cambia de dispositivo o usa modo incógnito, puede perder ese avance.

## Recomendación

No escribir claves, códigos, datos bancarios, números de documento ni información sensible dentro de campos libres o reportes copiables.
