# Política de privacidad base — CSS Práctico Web

El curso no solicita registro, no requiere correo electrónico y no envía información a servidores propios.

## Datos locales

El progreso, prácticas y configuraciones se guardan en el navegador mediante `localStorage`.

## Recomendación

No ingresar datos personales, contraseñas, información privada o contenido sensible en los campos de práctica.
