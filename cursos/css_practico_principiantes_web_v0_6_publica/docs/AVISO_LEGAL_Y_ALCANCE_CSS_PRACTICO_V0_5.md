# Aviso legal y alcance — CSS Práctico

Este curso tiene finalidad educativa e introductoria. Enseña conceptos básicos de CSS y prácticas orientativas para crear páginas simples.

No reemplaza:

- documentación oficial de CSS;
- revisión profesional de accesibilidad;
- pruebas exhaustivas en navegadores;
- asesoramiento técnico profesional para proyectos comerciales.

Los ejemplos generados son materiales de práctica y deben revisarse antes de usarse en un sitio real.
