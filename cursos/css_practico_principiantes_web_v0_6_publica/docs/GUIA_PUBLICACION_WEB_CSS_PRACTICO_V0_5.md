# Guía de publicación web — CSS Práctico v0.5

## Opciones recomendadas

- GitHub Pages.
- Netlify.
- Vercel.
- Carpeta estática dentro del portal Aula Digital Práctica.

## Antes de publicar

1. Probar con Live Server.
2. Revisar consola del navegador.
3. Confirmar que cargan los JSON.
4. Probar navegación principal.
5. Probar laboratorio CSS, constructor y landing.
6. Verificar Service Worker en entorno HTTPS o localhost.
7. Tomar capturas para `store/screenshots/`.

## Nota

Si se publica dentro de un portal con subcarpetas, revisar rutas relativas y cache del Service Worker.
