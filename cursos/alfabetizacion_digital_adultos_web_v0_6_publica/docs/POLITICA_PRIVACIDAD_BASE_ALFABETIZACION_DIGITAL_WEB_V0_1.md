# Política de privacidad base

Esta versión funciona localmente en el navegador.

- No requiere login.
- No tiene backend.
- No envía datos a servidores propios.
- No incluye publicidad.
- No incluye analíticas.
- El progreso se guarda en `localStorage` del navegador.

No se recomienda ingresar datos personales, contraseñas, códigos, información bancaria o documentos sensibles dentro del curso.
