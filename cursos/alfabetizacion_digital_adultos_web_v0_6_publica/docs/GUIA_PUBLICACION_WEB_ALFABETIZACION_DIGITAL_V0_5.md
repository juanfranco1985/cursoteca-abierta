# Guía de publicación web — Alfabetización Digital para Adultos v0.5

## Objetivo

Publicar el curso como sitio web estático.

## Requisitos

- Carpeta completa del proyecto.
- `index.html` en la raíz.
- `manifest.webmanifest` en la raíz.
- `service-worker.js` en la raíz.
- Carpeta `src/data/` incluida.
- Carpeta `icons/` incluida.

## Opciones recomendadas

### GitHub Pages

1. Crear repositorio.
2. Subir todos los archivos del proyecto.
3. Activar Pages desde la rama principal.
4. Probar la URL pública.

### Netlify

1. Entrar a Netlify.
2. Arrastrar la carpeta del proyecto o conectar repositorio.
3. Publicar como sitio estático.

### Vercel

1. Importar el repositorio.
2. Publicar sin framework especial.
3. Verificar que los JSON carguen correctamente.

## Pruebas después de publicar

- Abrir Home.
- Entrar a un módulo.
- Abrir una guía paso a paso.
- Usar el asistente de tareas.
- Activar modo simple.
- Marcar progreso.
- Cerrar y volver a abrir.
- Revisar modo móvil.
- Revisar consola del navegador.
