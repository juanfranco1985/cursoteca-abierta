# Estado actual — Alfabetización Digital para Adultos Web v0.2

## Objetivo de la versión

Agregar el núcleo diferencial del curso: **modo guía paso a paso** para tareas digitales frecuentes, con instrucciones grandes, simples, copiables e imprimibles.

## Funciones nuevas

- Ruta `#/step-guides`.
- Ruta `#/step-guide/{guideId}`.
- Archivo `src/data/step_guides.json`.
- 8 guías paso a paso.
- Buscador de guías.
- Filtro por categoría.
- Botón copiar pasos.
- Botón imprimir/guardar guía.
- Marcado local de guía practicada.
- Service Worker actualizado a cache v0.2.
- Validador actualizado para revisar guías.

## Estado

Versión funcional y validada. Próximo paso recomendado: v0.3 con asistente de tareas frecuentes y práctica guiada por escenarios.
