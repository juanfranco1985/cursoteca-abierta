# Política de privacidad base — Alfabetización Digital para Adultos Web

## Datos personales

La versión web no solicita registro, nombre, correo, teléfono ni documentos.

## Almacenamiento local

El progreso del curso se guarda en el navegador mediante `localStorage`.

Puede incluir:

- lecciones completadas;
- quizzes realizados;
- checklists marcados;
- guías practicadas;
- tareas consultadas.

## Datos que no se deben ingresar

El usuario no debe ingresar:

- contraseñas;
- códigos de verificación;
- datos bancarios;
- documentos personales;
- datos médicos;
- información privada de terceros.

## Backend, analíticas y publicidad

La versión base no usa backend, login, analíticas, publicidad ni tracking.

## Borrado de datos

El usuario puede borrar su progreso desde las opciones del curso o limpiando los datos del sitio en el navegador.
