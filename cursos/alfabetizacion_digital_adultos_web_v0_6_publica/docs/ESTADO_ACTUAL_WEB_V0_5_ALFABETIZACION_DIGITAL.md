# Estado actual — Alfabetización Digital para Adultos Web v0.5

## Estado

Versión candidata de publicación web.

## Resumen

El proyecto queda cerrado en su ciclo inicial como curso web educativo para adultos y personas mayores. Integra contenido modular, guías paso a paso, asistente de tareas frecuentes, modo simple, accesibilidad reforzada, progreso local y documentación de publicación.

## Componentes principales

- 6 módulos.
- 36 lecciones.
- 30 preguntas.
- 6 checklists.
- 8 casos guiados.
- 8 guías paso a paso.
- 10 tareas frecuentes.
- Modo simple.
- Panel de accesibilidad.
- Manifest web.
- Service Worker.
- Documentación pública.
