# POLÍTICA DE PRIVACIDAD BASE — FINANZAS DIGITALES SEGURAS WEB

## Datos personales

Esta versión no requiere registro, login, cuenta de usuario ni envío de datos a servidores propios.

## Almacenamiento local

El progreso del curso y algunas preferencias pueden guardarse localmente en el navegador mediante `localStorage`.

## Herramientas financieras

Las herramientas están pensadas para uso educativo. Se recomienda no ingresar datos sensibles, reales o identificatorios.

No ingresar:

- claves;
- tokens;
- códigos de verificación;
- números completos de tarjeta;
- DNI;
- CBU/CVU completos;
- alias reales si no es necesario;
- nombres completos de terceros;
- capturas reales de comprobantes.

## Analíticas y publicidad

Esta versión no incluye analíticas, publicidad ni tracking externo.

## Publicación futura

Si se agregan servicios externos, analíticas, formularios o backend, esta política debe actualizarse antes de publicar.
