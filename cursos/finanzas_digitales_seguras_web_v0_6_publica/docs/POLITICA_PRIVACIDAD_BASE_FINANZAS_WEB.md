# Política de privacidad base

Esta versión no tiene login, no usa backend, no envía progreso a servidores, no usa analíticas externas y no muestra publicidad.

El progreso se guarda localmente en el navegador mediante LocalStorage. Si el usuario borra datos del navegador, puede perder su avance.

El curso no solicita claves, PIN, token, códigos de verificación, números completos de tarjeta ni datos bancarios reales.
