# Estado actual — Finanzas Digitales Seguras Web v0.3

## Estado

Versión funcional para navegador basada en la plantilla clonable de cursos web.

## Incluye

- 6 módulos, 36 lecciones y 30 preguntas.
- 6 checklists y 8 casos guiados.
- Herramientas financieras educativas.
- Planificador de vencimientos y pagos.
- Exportación TXT de resultados.
- Diagnóstico imprimible.
- Checklists especiales para comprobante falso y movimiento desconocido.
