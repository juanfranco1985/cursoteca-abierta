# Estado actual — Finanzas Digitales Seguras Argentina Web v0.4

## Estado

Versión v0.4 enfocada en acabado funcional de herramientas, pequeños comercios y accesibilidad.

## Incluye

- Curso completo de 6 módulos, 36 lecciones y 30 preguntas.
- Checklists, casos financieros, modo emergencia y constancia interna.
- Herramientas educativas: presupuesto, gastos hormiga, cuota vs contado, margen simple, mensajes, diagnóstico, vencimientos, exportación y checklists críticos.
- Nuevo historial local opcional en `#/history`.
- Nueva guía para pequeños comercios en `#/commerce-guide`.
- Rutina imprimible de cobro seguro.
- Formularios con mejor área táctil y avisos de datos sensibles.

## Criterio de privacidad

El historial local debe guardar solo resúmenes educativos. No debe almacenar claves, DNI, CBU, CVU, alias reales, números completos de tarjeta, datos de clientes ni capturas.

## Próximo paso sugerido

La v0.5 debería orientarse a publicación: README público final, guía de capturas, política de privacidad, aviso legal específico, checklist de publicación y limpieza de documentación heredada.
