# ESTADO ACTUAL — Finanzas Digitales Seguras Web v0.2

## Estado

Versión funcional orientada a herramientas prácticas para usuarios, familias, comercios y emprendedores.

## Incluye

- 6 módulos educativos.
- 36 lecciones.
- 30 preguntas de quiz.
- 6 checklists.
- 8 casos financieros guiados.
- Progreso local con `localStorage`.
- PWA básica con manifest y Service Worker.
- Herramientas nuevas:
  - presupuesto mensual;
  - gastos hormiga;
  - cuota vs contado;
  - margen simple;
  - mensajes copiables;
  - diagnóstico de riesgo financiero digital.
