# Guía de publicación web — Tableau para Visualización de Datos v0.5

## Publicación recomendada

El curso puede publicarse como sitio estático en:

- GitHub Pages.
- Netlify.
- Vercel.
- Hosting estático propio.
- Portal de la Familia de Cursos Web.

## Pasos sugeridos

1. Probar localmente con VS Code + Live Server.
2. Revisar navegación completa.
3. Verificar laboratorios, reportes y descargas `.txt`.
4. Revisar `manifest.webmanifest`.
5. Revisar `service-worker.js`.
6. Crear capturas para portada, módulos, laboratorio, storyboard y storytelling.
7. Subir la carpeta completa al hosting elegido.

## Nota

No abrir directamente con doble clic sobre `index.html` para pruebas finales.
