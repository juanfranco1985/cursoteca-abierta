# Política de privacidad base — Tableau para Visualización de Datos Web

## Datos personales

El curso no solicita nombre, correo, cuenta, contraseña ni datos personales.

## Almacenamiento local

El avance se guarda en el navegador mediante `localStorage`.

## Servidores externos

La versión base no envía datos a servidores externos y no utiliza login, analíticas ni publicidad.

## Recomendación

No ingresar información real de empresas, clientes, estudiantes, ventas o datos sensibles en prácticas simuladas.
