# Guía de capturas — Tableau para Visualización de Datos v0.5

Capturas recomendadas:

1. Home del curso.
2. Módulos principales.
3. Laboratorio de visualizaciones.
4. Comparación de visualización correcta/incorrecta.
5. Constructor de dashboards/storyboards.
6. Simulador de presentación visual.
7. Checklist de claridad visual.
8. Constancia interna.

Las capturas deben mostrar datos de ejemplo, nunca datos reales de una persona u organización.
