# Aviso legal y alcance educativo — Tableau para Visualización de Datos

Este curso tiene finalidad educativa. No es una certificación oficial de Tableau, no reemplaza formación profesional ni garantiza dominio laboral de la herramienta.

Los ejemplos, datasets y reportes son simulados. No deben usarse para tomar decisiones empresariales reales sin validación profesional.

El curso evita solicitar datos personales, sensibles o empresariales reales.
