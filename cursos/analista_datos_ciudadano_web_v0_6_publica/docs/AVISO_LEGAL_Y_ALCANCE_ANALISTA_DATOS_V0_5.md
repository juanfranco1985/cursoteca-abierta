# AVISO LEGAL Y ALCANCE EDUCATIVO — Analista de Datos Ciudadano

Este curso web tiene finalidad educativa. Enseña conceptos básicos de análisis de datos cotidiano, organización de tablas, revisión de calidad, métricas simples, visualización inicial y comunicación prudente de hallazgos.

No reemplaza:

- asesoramiento estadístico profesional;
- asesoramiento contable;
- asesoramiento financiero;
- asesoramiento legal;
- auditoría profesional;
- consultoría de negocios;
- sistemas profesionales de BI o análisis avanzado.

Los ejemplos son simplificados. Antes de tomar decisiones reales, los datos, cálculos, supuestos y conclusiones deben verificarse con fuentes confiables y, si corresponde, con profesionales competentes.

No se garantiza exactitud, resultado económico, mejora de negocio ni detección completa de errores.
