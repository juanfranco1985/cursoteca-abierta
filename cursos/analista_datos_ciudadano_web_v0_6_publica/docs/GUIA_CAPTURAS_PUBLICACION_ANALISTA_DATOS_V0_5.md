# GUÍA DE CAPTURAS — Analista de Datos Ciudadano v0.5

## Capturas sugeridas

1. Home del curso.
2. Lista de módulos.
3. Lección abierta.
4. Laboratorio de tablas con muestra cargada.
5. Reporte generado por el laboratorio.
6. Práctica guiada paso a paso.
7. Resumen visual de prácticas.
8. Checklist imprimible de análisis ciudadano.
9. Constancia interna.
10. Pantalla de alcance y privacidad.

## Reglas para capturas públicas

- Usar solo tablas de ejemplo.
- No mostrar datos personales ni sensibles.
- No mostrar rutas locales privadas del equipo.
- Preferir resolución móvil y escritorio.
- Revisar ortografía antes de publicar.
