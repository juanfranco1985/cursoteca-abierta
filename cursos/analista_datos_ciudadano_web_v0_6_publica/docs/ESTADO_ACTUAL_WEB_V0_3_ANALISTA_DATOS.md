## Criterio educativo

El laboratorio no pretende reemplazar Excel, Power BI, Python ni análisis profesional. Su objetivo es enseñar pensamiento analítico básico: revisar calidad, calcular métricas simples, ordenar hallazgos, declarar límites y comunicar una recomendación responsable.

## Próximo paso recomendado

La v0.4 debería orientarse a experiencia de usuario y práctica guiada: mejores ejemplos, formularios más claros, más ayudas contextuales, historial visual de análisis y preparación hacia publicación.
