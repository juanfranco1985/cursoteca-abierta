# Aviso legal y alcance educativo

Analista de Datos Ciudadano es un curso educativo introductorio. No reemplaza asesoramiento estadístico, financiero, legal, contable ni profesional. Los ejemplos son simplificados y deben verificarse antes de tomar decisiones reales.

No se deben cargar claves, documentos, números de tarjeta, datos bancarios, datos personales sensibles ni información privada de terceros en ejemplos o reportes.
