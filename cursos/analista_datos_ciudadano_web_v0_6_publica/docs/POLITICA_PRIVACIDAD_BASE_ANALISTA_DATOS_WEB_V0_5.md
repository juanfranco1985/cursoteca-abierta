# POLÍTICA DE PRIVACIDAD BASE — Analista de Datos Ciudadano Web

## Resumen

La versión actual funciona en navegador y guarda el progreso de forma local.

## Datos

- No requiere registro.
- No solicita nombre, correo ni contraseña.
- No tiene backend propio.
- No usa analíticas externas.
- No usa publicidad.
- No envía progreso a servidores.

## LocalStorage

El progreso, historial educativo y preferencias pueden guardarse en `localStorage` del navegador. Si se borran los datos del navegador, se puede perder el avance.

## Laboratorio de tablas

El usuario no debe cargar datos personales, sensibles, financieros reales, médicos, laborales privados ni información de terceros sin anonimizar. Para práctica y capturas públicas se recomienda usar exclusivamente los datos de ejemplo incluidos.

## Hosting

Si el curso se publica en una plataforma externa, pueden aplicar políticas propias del proveedor de hosting.
