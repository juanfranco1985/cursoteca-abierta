# ESTADO ACTUAL — Analista de Datos Ciudadano Web v0.1

## Estado

Primera versión clonada del curso. Base navegable completa para navegador.

## Incluye

- 6 módulos pedagógicos.
- 36 lecciones.
- 30 preguntas de evaluación.
- 6 checklists.
- 8 misiones de análisis de datos.
- Persistencia local.
- Constancia interna.
- Manifest web y Service Worker.

## Base utilizada

Se tomó como referencia estructural la familia de cursos web y la variante de Finanzas Digitales Seguras v0.5 por su cercanía con herramientas y formularios.
