# ESTADO ACTUAL — Analista de Datos Ciudadano Web v0.5

## Estado

La versión **v0.5** deja el proyecto como **candidato de publicación web**. No busca agregar una herramienta analítica nueva, sino cerrar el paquete con documentación pública, privacidad, aviso legal, guía de publicación, guía de capturas, checklist de salida y validación técnica.

## Funcionalidad conservada

- Curso modular con 6 módulos y 36 lecciones.
- 30 preguntas de quiz.
- 6 checklists.
- 8 misiones de datos.
- Progreso local con `localStorage`.
- Constancia interna no oficial.
- Laboratorio de tablas.
- Carga de CSV propio.
- Detección educativa de faltantes, duplicados, categorías inconsistentes y valores fuera de escala.
- Métricas simples.
- Limpieza asistida.
- Columnas calculadas.
- Ranking top 5.
- Reporte exportable.
- Práctica guiada.
- Resumen visual e historial local sin tablas completas.

## Uso recomendado

Probar con VS Code + Live Server. Luego publicar como sitio estático en GitHub Pages, Netlify, Vercel, blog propio o servidor estático simple.

## Advertencia

No usar datos personales, sensibles, financieros reales ni privados en capturas públicas o pruebas compartidas. Para demostraciones usar los datasets de ejemplo incluidos.
