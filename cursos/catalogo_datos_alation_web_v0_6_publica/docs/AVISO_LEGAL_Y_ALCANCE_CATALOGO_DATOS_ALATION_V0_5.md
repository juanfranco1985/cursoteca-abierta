# Aviso legal y alcance educativo

Este curso es educativo y introductorio. No reemplaza formación corporativa oficial, consultoría profesional, políticas internas de gobierno de datos ni documentación oficial de proveedores.

El curso menciona Alation como referencia conceptual de herramientas de catálogo de datos, pero no representa una certificación oficial ni un material autorizado por dicha empresa.

Todos los datasets y escenarios son ficticios. No se deben ingresar datos reales, credenciales, nombres de clientes, nombres de sistemas internos ni información confidencial.
