# Estado actual — Catálogo de Datos y Alation Web v0.5

## Estado

Versión candidata de publicación.

## Objetivo

Cerrar el curso como paquete web educativo publicable, con documentación final, guía de publicación, guía de capturas, aviso legal, privacidad y checklist de publicación.

## Capacidades incluidas

- Curso de 6 módulos.
- 36 lecciones.
- 30 preguntas.
- 6 checklists.
- 8 casos guiados.
- Laboratorio de catálogo de datos simulado.
- Simulador de documentación de datasets.
- Laboratorio de gobierno, calidad, linaje e impacto de cambios.
- Checklist educativo de certificación de dataset.
- Exportación de reportes como `.txt`.
- Historial local no sensible.
- Manifest web.
- Service Worker.

## Recomendación posterior

Una posible v0.6 pública debería limpiar documentación interna, compactar el paquete y dejar solo archivos necesarios para usuario final.
