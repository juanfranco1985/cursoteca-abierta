# Política de privacidad base

Este curso funciona localmente en el navegador.

## Datos

- No requiere login.
- No envía datos a servidores.
- No incluye analíticas.
- No incluye publicidad.
- No solicita credenciales.
- El progreso se guarda localmente mediante `localStorage`.

## Recomendación

No ingresar datos personales, datos corporativos reales, credenciales, nombres de clientes, nombres de sistemas internos ni secretos comerciales.
