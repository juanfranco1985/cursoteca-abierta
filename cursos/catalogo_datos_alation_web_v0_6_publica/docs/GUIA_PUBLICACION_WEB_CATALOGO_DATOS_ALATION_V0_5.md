# Guía de publicación web — Catálogo de Datos y Alation v0.5

## Opción recomendada

Publicar como sitio estático en GitHub Pages, Netlify, Vercel o dentro de un portal propio de cursos.

## Pasos generales

1. Descomprimir el ZIP.
2. Probar con VS Code + Live Server.
3. Verificar navegación completa.
4. Revisar consola del navegador.
5. Probar recarga offline básica después de abrir una vez.
6. Subir carpeta completa a hosting estático.
7. Verificar `manifest.webmanifest` y `service-worker.js`.

## Estructura esperada

```text
index.html
styles.css
src/
icons/
manifest.webmanifest
service-worker.js
README.md
docs/
store/screenshots/
```
