# Política de privacidad base

Esta versión no usa login, backend, analíticas, publicidad ni tracking externo.

El progreso se guarda localmente en el navegador mediante `localStorage`.

El usuario puede reiniciar, exportar o importar su progreso desde las herramientas internas del curso.

No deben cargarse datos reales de usuarios, empresas, contraseñas, tokens ni información sensible en las actividades.
