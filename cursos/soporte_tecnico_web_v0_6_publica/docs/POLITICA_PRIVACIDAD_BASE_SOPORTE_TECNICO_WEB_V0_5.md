# Política de privacidad base — Soporte Técnico Web

La aplicación funciona localmente en el navegador.

## Datos

- No requiere cuenta.
- No solicita correo electrónico.
- No usa backend.
- No usa analíticas.
- No usa publicidad.
- No vende ni comparte datos.

## Almacenamiento local

Puede guardar en `localStorage`:

- progreso de lecciones;
- resultados de quizzes;
- checklists marcados;
- estados de tickets;
- bitácoras educativas;
- preferencias de accesibilidad.

Estos datos quedan en el dispositivo/navegador del usuario y pueden borrarse desde la configuración del navegador o desde las opciones internas del curso.
