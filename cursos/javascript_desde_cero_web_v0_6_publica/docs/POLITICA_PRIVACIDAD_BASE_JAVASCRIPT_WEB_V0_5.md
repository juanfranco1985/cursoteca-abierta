# POLÍTICA DE PRIVACIDAD BASE

Este curso funciona localmente en el navegador.

## Datos

No solicita:

- nombre real;
- correo electrónico;
- usuario;
- contraseña;
- datos personales;
- información sensible.

## Progreso

El progreso se guarda en `localStorage` del navegador.

## Servidores

El curso no envía información a servidores externos por sí mismo.

## Borrado

El usuario puede borrar el progreso limpiando los datos del navegador.
