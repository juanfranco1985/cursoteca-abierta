# ESTADO ACTUAL — JavaScript desde Cero Web v0.5

## Estado

Curso cerrado como candidato de publicación v0.5 dentro de la ruta **Desarrollo Web y Programación** de Aula Digital Práctica.

## Funcionalidades principales

- Curso completo con 6 módulos, 36 lecciones y 30 preguntas.
- Checklists prácticos.
- Casos guiados.
- Laboratorio JavaScript interactivo.
- Constructor de mini apps.
- Proyecto guiado de lista de tareas.
- Exportación de prácticas.
- Progreso local.
- Constancia interna no oficial.
- Manifest web.
- Service Worker.

## Núcleo diferencial

El núcleo diferencial del curso es la combinación de:

1. laboratorio interactivo;
2. constructor de mini apps;
3. proyecto guiado exportable.

Esto permite que el usuario no solo lea sobre JavaScript, sino que practique y genere pequeños proyectos.

## Próximo paso opcional

Una futura v0.6 pública podría limpiar documentación interna, reducir peso del paquete y preparar una carpeta final directamente publicable.
