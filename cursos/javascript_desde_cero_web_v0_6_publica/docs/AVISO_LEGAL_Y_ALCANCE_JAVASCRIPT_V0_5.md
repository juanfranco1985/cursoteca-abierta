# AVISO LEGAL Y ALCANCE EDUCATIVO

JavaScript desde Cero Web es un curso educativo introductorio.

No reemplaza:

- documentación oficial de JavaScript;
- formación profesional;
- revisión técnica especializada;
- auditoría de seguridad;
- buenas prácticas completas de producción.

Los ejemplos deben usarse en entornos de práctica.
