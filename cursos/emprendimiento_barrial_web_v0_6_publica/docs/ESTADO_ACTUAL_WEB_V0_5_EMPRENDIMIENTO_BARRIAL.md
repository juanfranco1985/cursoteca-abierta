# ESTADO ACTUAL WEB v0.5 — Emprendimiento Barrial

## Estado general

Emprendimiento Barrial Web queda como **candidato de publicación web v0.5**.

La versión conserva el curso completo, las herramientas de negocio, el simulador de decisiones, el tablero visual, la rutina semanal, los reportes imprimibles y la checklist diaria. Además agrega documentación pública final para publicar el proyecto como sitio estático.

## Base técnica

- HTML, CSS y JavaScript.
- Contenido local JSON.
- Progreso en `localStorage`.
- Manifest web.
- Service Worker básico.
- Sin backend.
- Sin login.
- Sin publicidad.
- Sin analíticas.

## Contenido

- 6 módulos.
- 36 lecciones.
- 30 preguntas de quiz.
- 6 checklists.
- 8 casos guiados de negocio.
- 6 casos de decisión.

## Funciones principales

- Curso modular.
- Quizzes.
- Checklists.
- Casos guiados.
- Acción rápida ante problemas del negocio.
- Herramientas de caja, margen, stock, promociones y mensajes.
- Simulador de decisiones.
- Tablero visual de decisiones.
- Rutina semanal.
- Reporte imprimible.
- Checklist diaria.
- Constancia interna no oficial.

## Documentación agregada en v0.5

- Guía de publicación web.
- Guía de capturas.
- Aviso legal y alcance educativo.
- Política de privacidad base.
- Checklist de publicación.
- Prompt de continuidad para v0.6.

## Próximo paso posible

Una eventual v0.6 debería limpiar documentación heredada, compactar el paquete, mejorar capturas reales y dejar una versión final pública liviana.
