# ESTADO ACTUAL — Emprendimiento Barrial Web v0.2

## Estado

Versión enfocada en herramientas prácticas de negocio barrial.

## Agregado principal

Se suma una capa de herramientas para ayudar a ordenar decisiones comunes de un pequeño emprendimiento:

- caja/presupuesto del negocio;
- gastos chicos;
- comparación compra contado vs cuotas;
- margen simple;
- control simple de stock;
- cierre de caja diaria;
- evaluador de promociones;
- mensajes copiables;
- diagnóstico de riesgo operativo;
- planificador de pagos;
- reportes exportables como TXT.

## Nota

Las herramientas son educativas. No guardan automáticamente datos sensibles y no reemplazan asesoramiento profesional.
