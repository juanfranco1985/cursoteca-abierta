# ESTADO ACTUAL WEB v0.4 - Emprendimiento Barrial

## Estado
Versión orientada a gestión práctica del negocio. El proyecto conserva el curso completo, herramientas de negocio y simulador de decisiones, y suma un tablero visual, rutina semanal, reporte imprimible y checklist diaria.

## Funciones agregadas

- `#/decision-dashboard`: tablero visual de decisiones practicadas.
- `#/weekly-routine`: rutina semanal del negocio.
- `#/printable-business-report`: reporte imprimible de caja, stock, precios y decisiones.
- `#/daily-operation-checklist`: checklist diaria de operación.

## Criterio de uso
La versión ayuda a que el usuario convierta el aprendizaje en rutina semanal y operación diaria, sin cargar datos sensibles ni depender de backend.
