# POLÍTICA DE PRIVACIDAD BASE — Emprendimiento Barrial Web

## Datos personales

La aplicación no solicita registro, nombre, correo electrónico ni datos personales.

## Almacenamiento local

El progreso, respuestas, historiales educativos y configuraciones se guardan localmente en el navegador mediante `localStorage`.

## Sin backend

No hay servidor propio, base de datos remota, login, analíticas, publicidad ni tracking incorporado.

## Recomendación

No cargar datos reales de clientes, claves, datos fiscales privados, información bancaria, datos comerciales sensibles ni información de terceros.

## Eliminación de datos

El usuario puede borrar datos desde las opciones internas del curso o limpiando datos del sitio desde el navegador.
