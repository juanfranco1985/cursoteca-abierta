# Estado actual — HTML Práctico para Principiantes Web v0.5

## Estado

Candidato de publicación.

## Objetivo de la versión

Cerrar el curso con documentación pública, guía de publicación, capturas sugeridas, aviso legal, política de privacidad y checklist de publicación.

## Funciones disponibles

- Curso base completo con 6 módulos, 36 lecciones y 30 preguntas.
- Checklists prácticos.
- Casos guiados.
- Laboratorio HTML interactivo.
- Constructor de página simple.
- Proyecto guiado de landing page básica.
- Exportación `.txt` y `.html`.
- Progreso local.
- Manifest web y Service Worker.

## Estado técnico

Validado con:

```bash
node --check src/app.js
node --check service-worker.js
node scripts/validate-template.mjs
```

v0.6 pública liviana: limpieza de documentación interna, ajuste final de textos visibles, revisión visual completa y paquete más liviano para publicación.
