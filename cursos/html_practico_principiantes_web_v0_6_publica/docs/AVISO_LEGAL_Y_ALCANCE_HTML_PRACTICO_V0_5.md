# Aviso legal y alcance educativo — HTML Práctico v0.5

Este curso tiene finalidad educativa e introductoria.

No reemplaza:

- documentación oficial de HTML;
- revisión profesional de código;
- auditoría de accesibilidad;
- validación completa de compatibilidad entre navegadores;
- formación profesional completa en desarrollo web.

Los ejemplos son simplificados para aprendizaje. Antes de usar código en un proyecto real, se recomienda revisarlo, probarlo y adaptarlo al contexto específico.
