# Política de privacidad base — HTML Práctico v0.5

## Datos personales

El curso no solicita datos personales.

## Almacenamiento local

El progreso y algunas prácticas pueden guardarse localmente en el navegador mediante `localStorage`.

## Servidores externos

La versión base no envía información a servidores externos.

## Recomendación

No ingresar contraseñas, correos personales, datos sensibles ni información privada dentro de ejemplos o prácticas.
