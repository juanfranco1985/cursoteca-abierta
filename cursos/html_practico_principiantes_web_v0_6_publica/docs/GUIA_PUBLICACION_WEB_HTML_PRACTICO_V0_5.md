# Guía de publicación web — HTML Práctico v0.5

## Opción recomendada

Publicar como sitio estático en GitHub Pages, Netlify o Vercel.

## Pasos generales

1. Descomprimir el ZIP.
2. Probar localmente con VS Code + Live Server.
3. Verificar navegación, quizzes, laboratorio, constructor y landing project.
4. Revisar consola del navegador.
5. Subir la carpeta a un repositorio o servicio de hosting estático.
6. Probar la URL pública.
7. Verificar que el Service Worker no conserve una versión anterior.

## Archivos clave

- `index.html`
- `styles.css`
- `src/app.js`
- `src/data/*.json`
- `manifest.webmanifest`
- `service-worker.js`
- `icons/icon.svg`
