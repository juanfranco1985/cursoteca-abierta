# ESTADO ACTUAL — HTML Práctico para Principiantes Web v0.2

## Estado

Versión v0.2 funcional con laboratorio HTML interactivo.

## Avance principal

Se agregó el núcleo diferencial del curso: un laboratorio para practicar HTML con ejemplos editables, vista previa simulada, ejercicios guiados, comparaciones correcto/incorrecto, fragmentos copiables y exportación `.txt`.

## Funciones incorporadas

- Ruta `#/html-lab`.
- Ruta `#/html-examples`.
- Ruta `#/html-example/{exampleId}`.
- Ruta `#/html-exercises`.
- Ruta `#/html-exercise/{exerciseId}`.
- Ruta `#/html-compare`.
- Ruta `#/html-snippets`.
- Archivo `src/data/html_lab.json`.
- Historial local no sensible de prácticas.
- Exportación de código como texto.
