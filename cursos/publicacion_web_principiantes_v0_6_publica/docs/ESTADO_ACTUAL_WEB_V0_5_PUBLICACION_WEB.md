# ESTADO ACTUAL — Publicación Web para Principiantes v0.5

## Estado

Curso cerrado como candidato de publicación v0.5 dentro de la ruta **Desarrollo Web y Programación** de Aula Digital Práctica.

## Funcionalidades principales

- Curso completo con 6 módulos, 36 lecciones y 30 preguntas.
- Checklists prácticos.
- Casos guiados.
- Laboratorio de publicación simulada.
- Selector de plataforma.
- Simulador de errores frecuentes.
- Constructor de proyecto publicable.
- Generador de landing simple.
- Generador de README de publicación.
- Proyecto guiado de publicación final.
- Simulación de deploy.
- Solución de errores.
- Checklist final.
- Progreso local.
- Constancia interna no oficial.
- Manifest web.
- Service Worker.

## Núcleo diferencial

El núcleo diferencial del curso es la combinación de:

1. laboratorio de publicación simulada;
2. constructor de proyecto publicable;
3. proyecto guiado de publicación final.

## Próximo paso opcional

Una futura v0.6 pública podría limpiar documentación interna, reducir peso del paquete y preparar una carpeta final directamente publicable.
