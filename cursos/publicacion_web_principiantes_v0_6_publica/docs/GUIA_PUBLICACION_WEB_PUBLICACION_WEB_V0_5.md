# GUÍA DE PUBLICACIÓN WEB — Publicación Web para Principiantes v0.5

## Opción recomendada para prueba

Usar VS Code + Live Server para validar el curso localmente.

## Publicación estática

El curso puede publicarse como sitio estático en:

- GitHub Pages.
- Netlify.
- Vercel.
- Servidor propio.
- Subcarpeta del portal Aula Digital Práctica.

## Pasos sugeridos

1. Descomprimir el ZIP.
2. Revisar `README.md`.
3. Abrir con Live Server.
4. Probar navegación principal.
5. Probar módulos y quizzes.
6. Probar laboratorio de publicación.
7. Probar selector de plataforma.
8. Probar simulador de errores.
9. Probar constructor de proyecto publicable.
10. Probar proyecto guiado final.
11. Probar reportes exportables.
12. Revisar consola del navegador.
13. Subir la carpeta al hosting elegido.

## Recomendación

Publicar primero como piloto interno antes de compartir ampliamente.
