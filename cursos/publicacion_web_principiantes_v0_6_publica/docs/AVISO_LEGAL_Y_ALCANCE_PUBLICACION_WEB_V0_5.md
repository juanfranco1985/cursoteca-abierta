# AVISO LEGAL Y ALCANCE EDUCATIVO

Publicación Web para Principiantes es un curso educativo introductorio.

No reemplaza:

- documentación oficial de GitHub Pages;
- documentación oficial de Netlify;
- documentación oficial de Vercel;
- formación profesional;
- auditoría de seguridad;
- revisión técnica especializada;
- operación profesional de hosting.

Las interfaces de plataformas externas pueden cambiar. Los laboratorios del curso son simulados.
