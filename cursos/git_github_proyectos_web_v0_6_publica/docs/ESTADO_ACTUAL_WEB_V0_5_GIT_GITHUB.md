# ESTADO ACTUAL — Git y GitHub para Proyectos Web v0.5

## Estado

Curso cerrado como candidato de publicación v0.5 dentro de la ruta **Desarrollo Web y Programación** de Aula Digital Práctica.

## Funcionalidades principales

- Curso completo con 6 módulos, 36 lecciones y 30 preguntas.
- Checklists prácticos.
- Casos guiados.
- Laboratorio Git simulado.
- Constructor de README.md.
- Constructor de .gitignore.
- Plantillas de commit.
- Proyecto guiado para subir una web a GitHub.
- Simulación de push.
- Checklist final.
- Progreso local.
- Constancia interna no oficial.
- Manifest web.
- Service Worker.

## Núcleo diferencial

El núcleo diferencial del curso es la combinación de:

1. laboratorio Git simulado;
2. constructor de documentación de repositorio;
3. proyecto guiado para subir una web a GitHub.
