# Aviso de uso publico

Este curso es material educativo. No ofrece garantias de resultado ni reemplaza asistencia profesional, legal, financiera, medica, tecnica, institucional o de seguridad cuando corresponda.

No ingreses datos sensibles reales en formularios, ejemplos, simuladores o herramientas. Si el curso trata situaciones delicadas, usa canales oficiales y conserva evidencia cuando sea necesario.
