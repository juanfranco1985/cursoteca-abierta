# GUÍA DE PUBLICACIÓN WEB — Git y GitHub para Proyectos Web v0.5

## Opción recomendada para prueba

Usar VS Code + Live Server para validar el curso localmente.

## Publicación estática

El curso puede publicarse como sitio estático en:

- GitHub Pages.
- Netlify.
- Vercel.
- Servidor propio.
- Subcarpeta del portal Aula Digital Práctica.

## Pasos sugeridos

1. Descomprimir el ZIP.
2. Revisar `README.md`.
3. Abrir con Live Server.
4. Probar navegación principal.
5. Probar laboratorio Git.
6. Probar constructor de README.
7. Probar constructor de .gitignore.
8. Probar proyecto guiado GitHub.
9. Probar exportaciones `.txt`, `.md` y `.gitignore`.
10. Revisar consola del navegador.
11. Subir la carpeta al hosting elegido.

## Recomendación

Publicar primero como piloto interno antes de compartir ampliamente.
