# AVISO LEGAL Y ALCANCE EDUCATIVO

Git y GitHub para Proyectos Web es un curso educativo introductorio.

No reemplaza:

- documentación oficial de Git;
- documentación oficial de GitHub;
- formación profesional;
- revisión técnica especializada;
- auditoría de seguridad;
- buenas prácticas completas de DevOps o control de versiones.

El laboratorio es simulado. No ejecuta comandos reales.
