# Política de privacidad base — Privacidad Digital Ciudadana Web

## Datos personales

La aplicación no solicita registro, login, correo electrónico ni datos personales obligatorios.

## Almacenamiento local

El progreso, historial educativo y preferencias se guardan localmente en el navegador mediante `localStorage`.

## Backend

No hay backend, servidor propio, base de datos externa, analíticas ni tracking incorporado en esta versión.

## Recomendación de uso

No ingresar información sensible, claves, números de teléfono, correos, datos de cuentas, nombres reales de apps ni información personal en las herramientas locales.

## Eliminación de datos locales

El usuario puede borrar el progreso desde la propia aplicación o limpiando los datos del sitio desde el navegador.
