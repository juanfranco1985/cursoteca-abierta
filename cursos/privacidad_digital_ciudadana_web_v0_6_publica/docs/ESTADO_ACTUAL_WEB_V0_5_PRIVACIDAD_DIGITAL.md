# Estado actual — Privacidad Digital Ciudadana Web v0.5

## Estado

Versión candidata de publicación web.

## Base técnica

- HTML, CSS y JavaScript.
- Datos locales en JSON.
- Progreso local con `localStorage`.
- Manifest web.
- Service Worker básico.
- Sin backend, sin login y sin base de datos externa.

## Funcionalidad incluida

- 6 módulos.
- 36 lecciones.
- 30 preguntas.
- 6 checklists.
- 8 casos guiados.
- Auditor local de permisos y privacidad.
- Guías paso a paso de configuración.
- Rutina ciudadana de privacidad.
- Checklist mensual imprimible.
- Reporte ciudadano exportable.
- Historial local no sensible.
- Constancia interna no oficial.
- Panel de accesibilidad.

## Cambio principal de v0.5

La versión se orienta a publicación y cierre: README público, guía de publicación, guía de capturas, aviso legal, política de privacidad, checklist final y carpeta `store/screenshots/`.

## Próxima versión opcional

v0.6 final pública: limpieza de documentación heredada, revisión visual final, capturas reales y preparación de demo online.
