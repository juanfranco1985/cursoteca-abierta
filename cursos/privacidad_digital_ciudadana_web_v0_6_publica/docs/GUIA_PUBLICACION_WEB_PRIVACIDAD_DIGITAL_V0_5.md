# Guía de publicación web — Privacidad Digital Ciudadana v0.5

## Requisitos

- Probar con VS Code + Live Server.
- Verificar que carguen todos los JSON.
- Verificar navegación principal.
- Probar auditor, guías, rutina, checklists y constancia.
- Confirmar que el Service Worker no tenga cache viejo en el navegador.

## Opciones de publicación

### GitHub Pages

1. Crear repositorio.
2. Subir el contenido de la carpeta del proyecto.
3. Activar Pages desde la rama principal.
4. Probar la URL pública.

### Netlify

1. Crear sitio nuevo.
2. Arrastrar la carpeta del proyecto o conectar repositorio.
3. Publicar como sitio estático.

### Vercel

1. Importar repositorio.
2. Usar configuración estática.
3. Publicar y probar rutas.

## Antes de publicar

- Revisar textos legales.
- Confirmar que no haya datos personales reales.
- Tomar capturas.
- Probar en celular.
- Probar en escritorio.
- Limpiar caches viejos del navegador.
