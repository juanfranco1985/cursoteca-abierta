# Curso 4 — Alfabetización Digital para Adultos

## Presentación del curso

La alfabetización digital ya no es un lujo ni una habilidad secundaria. Hoy muchas actividades cotidianas requieren algún nivel de manejo tecnológico: comunicarse con familiares, pedir turnos, consultar trámites, usar una billetera virtual, buscar información confiable, enviar documentos, mirar resultados médicos, acceder a cursos, usar mapas, leer noticias o protegerse de estafas.

Este curso está pensado para personas adultas que quieren ganar autonomía en el uso cotidiano de tecnologías digitales. No parte de la idea de que “todo el mundo ya sabe usar internet”. Al contrario: reconoce que muchas personas aprendieron a usar teléfonos, computadoras o aplicaciones de manera fragmentada, con ayuda de familiares o por necesidad, pero sin una base ordenada.

El objetivo no es enseñar tecnología como una lista de botones, sino construir confianza, criterio y autonomía. Una persona alfabetizada digitalmente no es quien sabe usar una aplicación de memoria, sino quien puede orientarse, aprender, preguntar, verificar, cuidarse y resolver problemas básicos en entornos digitales.

---

## Objetivos de aprendizaje

Al finalizar este curso, el estudiante debería poder:

1. Comprender qué significa estar alfabetizado digitalmente.
2. Identificar partes básicas de un celular, computadora, navegador y aplicación.
3. Buscar información en internet con criterios de confianza.
4. Comunicarse por medios digitales de manera clara y segura.
5. Usar correo electrónico, mensajería y formularios básicos.
6. Organizar archivos, fotos, documentos y contraseñas simples.
7. Realizar trámites digitales básicos con mayor autonomía.
8. Reconocer riesgos comunes: estafas, enlaces falsos, mensajes engañosos y exposición de datos.
9. Resolver problemas frecuentes sin depender totalmente de otra persona.
10. Crear un plan personal de aprendizaje digital continuo.

---

# Módulo 1 — Qué es la alfabetización digital

## 1.1 Más que “saber usar el celular”

Muchas personas usan el celular todos los días, pero eso no siempre significa que estén alfabetizadas digitalmente. Pueden enviar mensajes o mirar videos, pero sentirse perdidas cuando deben descargar un archivo, recuperar una contraseña, completar un formulario, identificar una página oficial o guardar un comprobante.

La alfabetización digital implica un conjunto de habilidades:

- usar dispositivos;
- buscar información;
- comunicarse;
- crear o completar contenidos;
- proteger datos;
- resolver problemas;
- aprender nuevas herramientas.

El marco DigComp organiza la competencia digital ciudadana en áreas como información, comunicación, creación de contenido, seguridad y resolución de problemas. Esa estructura es muy útil para pensar este curso.

## 1.2 Autonomía digital

La meta principal del curso es la autonomía. Autonomía no significa saberlo todo ni no pedir ayuda nunca. Significa poder realizar tareas básicas con más seguridad y saber cuándo una situación requiere apoyo.

Una persona con autonomía digital puede:

- reconocer una aplicación;
- diferenciar una página oficial de una dudosa;
- guardar un comprobante;
- enviar un archivo;
- buscar una solución;
- preguntar con claridad;
- evitar compartir datos sensibles;
- no actuar apurada ante mensajes sospechosos.

## 1.3 Aprender tecnología sin vergüenza

Uno de los mayores obstáculos para adultos principiantes no es técnico, sino emocional. Muchas personas sienten vergüenza por preguntar, miedo a romper algo, frustración o dependencia de hijos, nietos, vecinos o empleados.

Este curso parte de una idea central:

> Nadie nace sabiendo usar tecnología. Toda habilidad digital se aprende con práctica, paciencia y acompañamiento respetuoso.

# Módulo 2 — Dispositivos: celular, computadora y tablet

## 2.1 Qué es un dispositivo digital

Un dispositivo digital es una herramienta electrónica capaz de procesar información. Los más comunes son:

- celular;
- computadora de escritorio;
- notebook;
- tablet;
- smart TV;
- cajero automático;
- terminal de pago;
- reloj inteligente.

Cada dispositivo tiene formas distintas de entrada y salida: pantalla, teclado, mouse, cámara, micrófono, parlantes, huella, botones o pantalla táctil.

## 2.2 Celular

El celular es para muchas personas el principal acceso a internet. Permite comunicarse, sacar fotos, usar aplicaciones, pagar, buscar información y hacer trámites.

Partes importantes:

- pantalla;
- botones físicos;
- cámara;
- micrófono;
- parlante;
- batería;
- cargador;
- tarjeta SIM;
- almacenamiento;
- conexión Wi-Fi;
- datos móviles.

## 2.3 Computadora

La computadora suele ser más cómoda para tareas largas:

- escribir documentos;
- completar formularios extensos;
- organizar archivos;
- estudiar;
- trabajar con planillas;
- imprimir;
- descargar y ordenar documentos.

Componentes básicos:

- monitor;
- teclado;
- mouse;
- gabinete o notebook;
- puertos USB;
- sistema operativo;
- navegador;
- carpetas;
- archivos.

## 2.4 Tablet

La tablet combina elementos del celular y la computadora. Puede ser útil para leer, estudiar, ver videos, comunicarse, consultar trámites o hacer videollamadas.

## 2.5 No todos los dispositivos funcionan igual

Una dificultad frecuente es que alguien aprende un paso en un celular y luego no lo encuentra igual en otro. Esto sucede porque cambian:

- marcas;
- sistemas operativos;
- versiones;
- tamaños de pantalla;
- configuraciones;
- nombres de botones.

Por eso este curso enseña principios generales, no solo instrucciones rígidas.

# Módulo 3 — Internet, navegador y páginas web

## 3.1 Qué es internet

Internet es una red global que conecta computadoras, servidores, celulares y otros dispositivos. Gracias a internet podemos enviar mensajes, ver páginas, usar mapas, mirar videos, comprar, estudiar y acceder a servicios.

Internet no es una sola aplicación. WhatsApp, Google, YouTube, Facebook, correo electrónico y páginas oficiales usan internet, pero no son lo mismo.

## 3.2 Qué es un navegador

El navegador es la aplicación que permite visitar páginas web. Algunos navegadores conocidos son:

- Google Chrome;
- Microsoft Edge;
- Mozilla Firefox;
- Safari;
- Samsung Internet.

El navegador tiene una barra de direcciones donde se escribe el sitio web o una búsqueda.

## 3.3 Página web, buscador y aplicación

Es importante distinguir:

- Página web: sitio al que se accede desde navegador.
- Buscador: herramienta para encontrar páginas, como Google o Bing.
- Aplicación: programa instalado en celular o computadora.
- Portal oficial: sitio web de una institución, organismo o empresa.

Confundir buscador con página oficial es un error común. Buscar “ANSES” en Google no es lo mismo que verificar que se entró efectivamente al sitio oficial.

## 3.4 Dirección web

Una dirección web indica dónde está una página. Por ejemplo, los sitios oficiales argentinos suelen terminar en `gob.ar` o estar dentro de `argentina.gob.ar`.

Antes de ingresar datos, conviene revisar:

- dirección del sitio;
- candado de seguridad;
- nombre del organismo;
- errores de escritura;
- anuncios disfrazados;
- enlaces enviados por terceros.

# Módulo 4 — Buscar información confiable

## 4.1 Buscar no es lo mismo que encontrar verdad

Internet contiene información útil, pero también errores, publicidad, rumores, estafas, opiniones disfrazadas de hechos y contenidos desactualizados.

Al buscar información, hay que preguntarse:

- ¿quién lo publica?
- ¿cuándo fue publicado?
- ¿qué fuente usa?
- ¿es un sitio oficial?
- ¿hay intención de vender algo?
- ¿otros sitios confiables dicen lo mismo?
- ¿el título exagera?

## 4.2 Tipos de fuentes

Fuentes más confiables para temas importantes:

- organismos oficiales;
- universidades;
- hospitales reconocidos;
- medios periodísticos profesionales;
- documentación técnica oficial;
- instituciones internacionales;
- manuales educativos;
- sitios de empresas cuando se consulta sobre sus propios productos.

Fuentes que requieren más cuidado:

- cadenas de WhatsApp;
- videos sin autor claro;
- publicaciones virales;
- capturas de pantalla;
- blogs anónimos;
- comentarios en redes;
- páginas con títulos sensacionalistas.

## 4.3 Búsqueda práctica

Para buscar mejor:

- escribir palabras específicas;
- agregar país o ciudad si corresponde;
- usar nombres oficiales;
- comparar resultados;
- evitar hacer clic en cualquier anuncio;
- guardar enlaces confiables;
- verificar fechas.

Ejemplo débil:

> turno dni

Ejemplo mejor:

> turno DNI Argentina Registro Civil Santa Fe

Ejemplo más seguro:

> sitio oficial turno DNI Argentina

## 4.4 Información sensible

Para temas médicos, legales, financieros o administrativos, no conviene confiar en una sola publicación informal. Es mejor consultar fuentes oficiales o profesionales.

# Módulo 5 — Comunicación digital

## 5.1 Canales de comunicación

Los canales más comunes son:

- WhatsApp;
- correo electrónico;
- SMS;
- videollamadas;
- redes sociales;
- formularios web;
- chats de atención;
- aplicaciones institucionales.

Cada canal tiene usos distintos.

WhatsApp sirve para comunicación rápida. El correo sirve mejor para documentos, trámites, comprobantes y mensajes formales. Las videollamadas sirven para reuniones o consultas. Los formularios sirven para enviar datos ordenados.

## 5.2 Comunicación clara

Un mensaje digital claro debe incluir:

- saludo;
- motivo;
- datos necesarios;
- pedido concreto;
- despedida;
- archivo adjunto si corresponde.

Ejemplo débil:

> Hola, necesito eso.

Ejemplo claro:

> Buen día. Necesito consultar el estado de mi trámite de renovación. Mi número de expediente es X. Adjunto comprobante. Gracias.

## 5.3 Cuidado con lo que se envía

Antes de enviar un mensaje, revisar:

- destinatario correcto;
- archivos correctos;
- datos personales;
- tono;
- ortografía mínima;
- si corresponde responder por privado o públicamente.

No todo debe enviarse por cualquier canal. Datos como claves, códigos de verificación, fotos de documentos, tarjetas o información bancaria requieren extremo cuidado.

## 5.4 Videollamadas

Para una videollamada básica se necesita:

- conexión estable;
- cámara y micrófono;
- enlace o aplicación;
- lugar con algo de silencio;
- batería o cargador;
- probar audio antes;
- saber activar o desactivar micrófono.

# Módulo 6 — Correo electrónico

## 6.1 Para qué sirve el correo

El correo electrónico sigue siendo clave para:

- crear cuentas;
- recuperar contraseñas;
- recibir comprobantes;
- enviar documentos;
- recibir turnos;
- comunicarse formalmente;
- registrarse en plataformas;
- recibir notificaciones oficiales.

Aunque muchas personas usen más WhatsApp, el correo sigue siendo una identidad digital importante.

## 6.2 Partes de un correo

Un correo tiene:

- destinatario;
- asunto;
- cuerpo del mensaje;
- archivos adjuntos;
- firma;
- fecha;
- remitente.

El asunto debe ser claro.

Ejemplo:

> Consulta por turno médico — Juan Pérez

## 6.3 Adjuntar archivos

Adjuntar significa enviar un archivo junto con el correo: PDF, foto, documento, comprobante o planilla.

Antes de adjuntar:

- revisar que sea el archivo correcto;
- verificar que se vea bien;
- controlar tamaño;
- renombrar si es necesario;
- no enviar documentos sensibles a direcciones dudosas.

## 6.4 Correos sospechosos

Señales de alerta:

- piden claves;
- amenazan con bloquear cuenta;
- ofrecen premios;
- tienen errores raros;
- llegan de direcciones extrañas;
- incluyen enlaces acortados;
- generan urgencia;
- piden códigos de verificación.

# Módulo 7 — Archivos, fotos y documentos

## 7.1 Qué es un archivo

Un archivo es una unidad de información guardada en un dispositivo. Puede ser:

- foto;
- video;
- documento;
- PDF;
- audio;
- planilla;
- presentación;
- comprobante;
- imagen descargada.

## 7.2 Carpetas

Las carpetas sirven para ordenar archivos. Una organización básica puede ser:

- Documentos personales;
- Salud;
- Trabajo;
- Estudios;
- Trámites;
- Comprobantes;
- Fotos familiares;
- Facturas.

El orden digital evita pérdidas y reduce dependencia.

## 7.3 Nombres de archivos

Un archivo llamado `IMG_20260103_1545.jpg` puede ser difícil de identificar.

Mejor:

> comprobante_luz_enero_2026.jpg

O:

> turno_medico_abril_2026.pdf

## 7.4 PDF

El PDF es un formato común para documentos, comprobantes, constancias, facturas y formularios. Es importante saber abrirlo, guardarlo y enviarlo.

## 7.5 Copias de seguridad

Una copia de seguridad permite recuperar información si se pierde el celular, se rompe la computadora o se borra algo por error.

Opciones:

- nube;
- pendrive;
- disco externo;
- copia en otro dispositivo;
- correo propio;
- carpeta compartida segura.

# Módulo 8 — Trámites digitales

## 8.1 Qué es un trámite digital

Un trámite digital es una gestión que se realiza total o parcialmente por internet. Puede incluir:

- solicitar turno;
- completar formulario;
- cargar documentación;
- consultar expediente;
- pagar tasa;
- descargar constancia;
- recibir notificación.

En Argentina, existen plataformas oficiales para trámites y servicios digitales.

## 8.2 Antes de iniciar un trámite

Preparar:

- documento de identidad;
- correo activo;
- celular;
- contraseña o clave requerida;
- fotos o PDFs;
- datos personales actualizados;
- comprobantes;
- conexión estable;
- tiempo suficiente.

Muchas frustraciones aparecen porque se empieza un trámite sin tener los documentos listos.

## 8.3 Durante el trámite

Buenas prácticas:

- leer cada pantalla;
- no apurarse;
- revisar datos antes de enviar;
- guardar número de trámite;
- descargar comprobante;
- sacar captura solo si no hay opción de descarga;
- anotar fecha;
- cerrar sesión al terminar.

## 8.4 Después del trámite

Guardar:

- comprobante;
- número de expediente;
- correo recibido;
- fecha;
- contraseña usada si corresponde;
- próximos pasos.

Un trámite no termina al hacer clic en “enviar”. Termina cuando se sabe cómo consultar, corregir o continuar.

# Módulo 9 — Seguridad digital básica

## 9.1 Riesgos comunes

Los riesgos más frecuentes para adultos principiantes son:

- estafas por WhatsApp;
- llamadas falsas;
- correos engañosos;
- enlaces falsos;
- robo de cuentas;
- pérdida de celular;
- compartir códigos;
- contraseñas débiles;
- instalación de aplicaciones dudosas;
- compras en sitios no confiables.

## 9.2 Regla de oro

> Nadie confiable debería pedirte tu contraseña, código de verificación, PIN, token bancario o clave de seguridad por mensaje o llamada.

Si alguien pide esos datos, hay que detenerse y verificar por otro canal.

## 9.3 Contraseñas

Buenas prácticas:

- usar contraseñas largas;
- no repetir la misma en todo;
- evitar fechas personales;
- no anotarlas en papeles visibles;
- activar segundo factor cuando sea posible;
- cambiar contraseñas si hay sospecha.

## 9.4 Enlaces

Antes de tocar un enlace:

- mirar quién lo envía;
- preguntarse si se esperaba ese mensaje;
- revisar si genera urgencia;
- no ingresar claves desde enlaces dudosos;
- buscar la página oficial por cuenta propia.

## 9.5 Celular perdido o robado

Medidas preventivas:

- bloqueo de pantalla;
- copia de seguridad;
- cuenta configurada;
- no guardar claves en notas visibles;
- saber cómo bloquear SIM;
- tener datos de contacto de banco o billetera;
- activar localización si se desea.

# Módulo 10 — Resolución de problemas

## 10.1 Aprender a diagnosticar

Cuando algo no funciona, conviene preguntar:

- ¿qué estaba intentando hacer?
- ¿qué mensaje apareció?
- ¿desde cuándo ocurre?
- ¿hay internet?
- ¿la contraseña es correcta?
- ¿la aplicación está actualizada?
- ¿el dispositivo tiene batería?
- ¿hay espacio disponible?
- ¿probé cerrar y abrir?
- ¿puedo hacer captura del error?

## 10.2 No tocar todo al azar

Un error común es empezar a tocar botones sin leer. Eso puede generar más confusión.

Método recomendado:

1. detenerse;
2. leer mensaje;
3. anotar o capturar;
4. buscar explicación;
5. probar una solución simple;
6. pedir ayuda si hace falta.

## 10.3 Pedir ayuda correctamente

Pedir ayuda bien también es una habilidad digital.

En vez de decir:

> No anda.

Mejor decir:

> Estoy intentando entrar a mi correo. Escribo la contraseña y aparece “contraseña incorrecta”. Me pasa desde hoy. Estoy usando el celular.

Esto facilita que otra persona ayude sin manipular todo por uno.

# Módulo 11 — Aprendizaje digital continuo

## 11.1 La tecnología cambia

Aplicaciones, botones y pantallas cambian. Por eso la alfabetización digital no puede basarse solo en memorizar pasos.

Es mejor aprender principios:

- buscar;
- leer;
- verificar;
- guardar;
- proteger;
- preguntar;
- practicar;
- comparar;
- resolver.

## 11.2 Plan personal

Cada estudiante debería definir tres objetivos concretos.

Ejemplos:

- aprender a enviar correos con adjuntos;
- hacer trámites online sin ayuda;
- ordenar fotos y documentos;
- reconocer mensajes sospechosos;
- usar videollamadas;
- guardar comprobantes;
- buscar información confiable.

## 11.3 Práctica segura

La confianza se construye con práctica. Conviene practicar primero con tareas de bajo riesgo:

- buscar una receta;
- enviar un correo de prueba;
- guardar una foto;
- crear una carpeta;
- descargar un PDF educativo;
- hacer una videollamada familiar;
- completar un formulario no sensible.

Luego avanzar hacia tareas más importantes.

# Caso práctico integrador

## Caso: Marta quiere hacer un trámite y comunicarse con su familia

Marta tiene 62 años. Usa WhatsApp, pero se siente insegura con el correo y los trámites digitales. Necesita pedir un turno, guardar el comprobante y enviárselo a su hija por correo.

### Paso 1 — Preparar datos

Marta reúne:

- DNI;
- celular cargado;
- correo electrónico;
- contraseña;
- conexión Wi-Fi;
- datos del trámite.

### Paso 2 — Buscar sitio oficial

No entra desde un enlace enviado por desconocidos. Busca el organismo oficial y revisa la dirección.

### Paso 3 — Completar formulario

Lee cada campo, completa datos, revisa antes de enviar y evita apurarse.

### Paso 4 — Guardar comprobante

Descarga el PDF o toma captura si no hay opción de descarga. Lo guarda en una carpeta llamada “Trámites”.

### Paso 5 — Enviar por correo

Abre su correo, escribe destinatario, asunto claro, mensaje breve y adjunta el comprobante.

### Paso 6 — Registrar

Anota fecha, número de trámite y dónde guardó el archivo.

# Actividades del curso

## Actividad 1 — Mapa personal digital

Hacer una lista de:

- dispositivos que uso;
- aplicaciones que uso;
- cuentas importantes;
- tareas que ya puedo hacer;
- tareas que quiero aprender;
- personas o lugares donde puedo pedir ayuda.

## Actividad 2 — Búsqueda confiable

Buscar información sobre un trámite real y responder:

- ¿qué sitio encontré?
- ¿es oficial?
- ¿cómo lo sé?
- ¿qué documentos pide?
- ¿qué dudas quedan?

## Actividad 3 — Correo con adjunto

Enviar un correo de práctica a una persona de confianza con:

- asunto claro;
- saludo;
- mensaje breve;
- archivo adjunto;
- despedida.

## Actividad 4 — Organización de archivos

Crear o imaginar una estructura de carpetas:

- Trámites;
- Salud;
- Comprobantes;
- Trabajo;
- Familia;
- Fotos.

Renombrar al menos tres archivos de forma clara.

## Actividad 5 — Detectar estafas

Analizar tres mensajes sospechosos y marcar:

- quién lo envía;
- qué pide;
- qué emoción intenta provocar;
- qué dato sensible solicita;
- qué haría antes de responder.

# Glosario básico

Alfabetización digital: conjunto de habilidades para usar tecnologías digitales de manera autónoma, segura, crítica y práctica.

Autonomía digital: capacidad de resolver tareas digitales básicas y pedir ayuda de manera informada cuando sea necesario.

Dispositivo: herramienta electrónica como celular, computadora, tablet o cajero.

Internet: red global que conecta dispositivos y permite acceder a servicios digitales.

Navegador: aplicación para visitar páginas web.

Buscador: herramienta para encontrar información en internet.

Página web: documento o conjunto de contenidos accesible desde un navegador.

Aplicación: programa instalado en un dispositivo.

Correo electrónico: sistema para enviar y recibir mensajes digitales.

Archivo: unidad de información guardada, como foto, PDF, documento o video.

Carpeta: espacio para organizar archivos.

PDF: formato común para documentos digitales.

Adjunto: archivo que se envía junto con un correo o mensaje.

Contraseña: clave secreta para acceder a una cuenta.

Segundo factor: verificación adicional para proteger una cuenta.

Phishing: engaño digital para obtener claves, datos o dinero.

Trámite digital: gestión administrativa realizada total o parcialmente por internet.

Sitio oficial: página perteneciente a una institución, organismo o empresa real.

Comprobante digital: documento o archivo que prueba que se realizó una operación.

# Producto final del curso

Al finalizar, el estudiante debe crear una **Carpeta Digital Personal Básica** y un **Plan de Autonomía Digital de 30 días**.

La carpeta debe ordenar documentos, cuentas, trámites y comprobantes. El plan debe incluir tareas progresivas, por ejemplo:

- semana 1: practicar correo y archivos;
- semana 2: buscar información confiable;
- semana 3: realizar un trámite simple;
- semana 4: revisar seguridad de cuentas.
