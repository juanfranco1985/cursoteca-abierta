# Cursoteca Abierta — Investigación profesional web v0.9

Fecha: 2026-06-05

Este paquete traduce la etapa solicitada a un formato utilizable por Codex o por un editor humano: investigación teórica por curso, fuentes base, marco profesional y estructura de reescritura.

## Alcance real
- No copia contenido de la web.
- Sintetiza fuentes oficiales, documentación primaria y marcos reconocidos.
- Traduce el enfoque al español y al contexto de Cursoteca Abierta.
- Deja una base para reescribir cada curso con alto contenido teórico.

## Estándar objetivo por curso
Cada curso profesionalizado debe incluir:
1. problema que resuelve;
2. marco teórico;
3. conceptos centrales;
4. glosario;
5. modelos o marcos de referencia;
6. caso práctico;
7. errores frecuentes;
8. actividad final;
9. evaluación;
10. fuentes recomendadas.

## Advertencia editorial
Los cursos vinculados a temas legales, fiscales, financieros, seguridad o salud digital deben incluir aviso de alcance: contenido educativo, no asesoramiento profesional personalizado.
