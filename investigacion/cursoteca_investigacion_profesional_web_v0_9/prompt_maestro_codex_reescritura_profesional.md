# Prompt maestro para Codex — Reescritura profesional de cursos

Usa la matriz `matriz_50_cursos_investigacion_web_v0_9.csv` y el documento `documento_maestro_50_cursos.md`.
Objetivo: convertir cada curso existente en una versión profesional, con alto contenido teórico, práctica guiada y evaluación.

Reglas:
1. No copies texto de fuentes externas.
2. Sintetiza y traduce al español con estilo claro.
3. Mantén nivel inicial/intermedio, pero con rigor conceptual.
4. Agrega glosario, errores frecuentes y checklist.
5. Incluye aviso de alcance para temas fiscales, legales, financieros, seguridad o salud.
6. Cada curso debe tener mínimo:
   - presentación del problema;
   - marco teórico;
   - 6 módulos;
   - caso práctico;
   - actividad final;
   - evaluación;
   - fuentes recomendadas.
7. Preserva rutas y slugs del proyecto actual.
8. Antes de modificar código o HTML, crear respaldo.
